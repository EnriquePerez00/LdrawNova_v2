ARCHITECTURE SUMMARY
================================================================================

5-AGENT ORCHESTRATION:

┌─────────────────────────────────────────────────────────────┐
│         IMPROVEMENT LOOP (ldraw_tools/improvement_loop.py)  │
│              (Originally FASE 0-1, extended FASE 2-7)       │
└─────────────────────────────────────────────────────────────┘

[A1] DESCRIPTOR GT
     Input: GT image(s)
     Output: spec.json (description + segments + volumes)
     Model: Sonnet 4.8 (once per design, cached)

[LOOP 0..N-1]
  ├─ [A2] DESIGNER 3D
  │   Input: spec.json + feedback (diffs)
  │   Output: plan.json → .mpd
  │   Model: Sonnet 4.x (guided by spec + ShapeMatcher candidates)
  │
  ├─ [VALIDATORS] Deterministic (no LLM)
  │   - Geometry: overlaps, connectivity
  │   - BOM: compare-bom
  │   - Color: ΔE per segment (CIELAB)
  │
  ├─ [A3] DESCRIPTOR-INVERSO (Blind to GT)
  │   Input: 4 renders (home, front, right, top)
  │   Output: render_spec.json (same structure as spec.json)
  │   Model: **Haiku 4.x** (cheap, repetitive, 4×N iterations)
  │
  ├─ [A4] JUDGE/DIFFER
  │   Input: spec_gt + render_spec + visual (images) + renders/
  │   Output: diff_report.json (diffs anchored to location + severity)
  │   Model: Sonnet 4.8 → Opus 4.x (escalate on stagnation)
  │
  └─ [ORCHESTRATOR]
      ├─ Compute global_score (Σ weighted per_axis_scores)
      ├─ Check convergence (3-way OR)
      ├─ Hill-climbing anti-regression (track best, revert if needed)
      ├─ Select top-N diffs for next iteration feedback
      └─ Persist loop_state.json (memory)

[ProfileAdapter] (FASE 2)
  - Domain-specific customization
  - scoring_weights (customizable per profile)
  - evaluation_rubric
  - volume_to_part_matcher
  - No CORE loop duplication

[ShapeMatcher] (FASE 3)
  - Quantitative volume→part matching
  - fit_scores 0-100 enable metric-driven feedback
  - Primitive types: flat_tile, curved_arc, slope, rounded_corner

[ModelRouter] (FASE 6)
  - Context-aware model selection
  - Stagnation detection (last 2 scores)
  - Escalation logic (Sonnet→Opus on plateau)
  - 60-70% cost savings via Haiku for A3
