                  (handles markdown, raw, embedded)

================================================================================
KEY FEATURES
================================================================================

1. **Multi-Image Support**
   - vlm_chat() accepts List[Path] (e.g., 4 render views)
   - Each image → base64 data URI
   - Supports PNG, JPEG, GIF, WebP

2. **JSON Parsing Robustness**
   - Markdown: ```json { ... } ```
   - Raw: { ... }
   - Embedded: text before/after JSON
   - Fallback: returns default dict

3. **Escalation Logic (A4)**
   - Tracks score_history per job_id
   - Detects stagnation: last 2 scores no improvement
   - Escalates: gemini-2.5-flash → gemini-2.5-pro
   - Resets counter on improvement

4. **Fallback System**
   - Primary: Cline LiteLLM at localhost:6655
   - Fallback: Ollama at localhost:11434
   - Automatic retry on connection/timeout errors
   - Seamless degradation

5. **Cost Optimization**
   - A1 (1x per design): gemini-2.5-flash
   - A2 (repeated): claude-haiku-5 (code only, no images)
   - A3 (4x per iteration): gemini-2.5-flash
   - A4 (escalates on need): flash → pro
   - Result: ~40% savings vs. always using pro
