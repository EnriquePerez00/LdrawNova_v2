================================================================================
COMPLETE 5-AGENT LOOP
================================================================================

[Input: spec.json (GT description)]

A1: Descriptor GT (VLM – gemini-2.5-flash)
    └→ spec.json (once per design, cached)

[For each iteration 0..N-1:]

    A2: Designer 3D (LLM – claude-haiku-5)
        Input: spec.json + feedback from previous iteration
        Output: design.mpd (LDraw code)
    
    [Validators]
        └ GeometryValidator → syntax check + whitelist
        └ BOMValidator → part count + constraints
        └ ColorValidator → ΔE palette matching
    
    [Rendering Pipeline]
        └ LeoCAD → 4 PNG views (home/front/right/top)
        └ ColorExtractor → K-means on renders
        └ OverlapDetector → Edge detection
    
    A3: Descriptor Inverso (VLM – gemini-2.5-flash)
        Input: 4 PNG renders (blind to GT)
        Output: render_spec.json
    
    A4: Judge/Differ (VLM – gemini-2.5-flash → pro on stagnation)
        Input: spec.json + render_spec.json + 4 PNGs
        Output: diff_report.json (score + diffs)
    
    [State Persistence]
        └ loop_state.json → iteration history + best tracking
    
    [Convergence Check]
        if score >= threshold OR severity < 4 OR iter >= max_iter:
            BREAK
        else:
            Continue to next iteration

[Output: output/best/design.mpd + loop_state.json]

KEY INNOVATIONS
================================================================================

1. COST OPTIMIZATION
   A1/A3/A4 use gemini-2.5-flash (cheap, fast VLM)
   A2 uses claude-haiku-5 (cheapest text LLM)
   A4 escalates to gemini-2.5-pro only on plateau detection
   Result: ~40-50% savings vs. high-end models everywhere

2. MULTI-MODAL VALIDATION
   └ Symbolic: JSON specs (A3 blind description vs A1 GT)
   └ Visual: 4-view renders with color + overlap analysis
   └ Structural: BOM + geometry whitelist checks
   └ Chromatic: ΔE color distance to standard LEGO palette

3. RENDERING INTEGRATION
   └ LeoCAD 4-view output per iteration
   └ Automatic color extraction (K-means)
   └ Automatic overlap detection (Sobel edges)
   └ Placeholder fallback if LeoCAD unavailable (still testable)

4. RESUMABLE LOOPS
   └ loop_state.json tracks all iterations
   └ Best iteration tracking (anti-regression)
   └ Feedback.json for next iteration
   └ Can pause/resume at any iteration

5. PROMPT ENGINEERING
   └ A1: Multi-image VLM analyzing GT
   └ A2: LLM generating LDraw syntax from specs
   └ A3: VLM describing renders WITHOUT GT reference (anti-bias)
   └ A4: VLM comparing two specs + visual inspection

```python
from ldraw_tools.improvement_loop_v2 import ImprovementLoopV2
from ldraw_tools import agent_roles
from profiles.brand_logo import BrandLogoAdapter

spec = {"version": 1, "segments": [{"name": "logo"}]}
adapter = BrandLogoAdapter()

loop = ImprovementLoopV2(
    spec=spec,
    adapter=adapter,
    output_dir="output/my_logo",
    max_iter=4,
    threshold=85.0,
    ldraw_dir="/Users/I764690/LDraw",
)

result = loop.run(
    agent_roles=agent_roles,
    feedback=None,
    llm_config={
        "base_url": "http://localhost:6655/litellm",
        "secret": "<REDACTED-set-in-env>",
    }
)

print(f"Converged: {result['converged']}, Best score: {result['best']['score']}")
```
